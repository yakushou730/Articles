6. 用簡單的 API 啟動、暫停、恢復（Launch/Pause/Resume with simple APIs）

代理就是程式。我們對「如何啟動、查詢、恢復、停止程式」本來就有一些期待。

GIF 版本

使用者、應用程式、pipeline 與其他代理，都應該能用簡單的 API 啟動一個代理。

代理與負責協調的確定性程式碼，應該能在需要長時間操作時把代理暫停。

webhook 這類外部觸發，應該能讓代理從中斷處恢復，而不必與代理協調者深度整合。

這和要素 5：統合執行狀態與業務狀態、要素 8：自己掌握控制流密切相關，但可以獨立實作。

注意：AI 協調者通常允許暫停與恢復，但沒辦法在「選好工具」與「實際執行工具」之間暫停。另見要素 7：用工具呼叫聯絡真人與要素 11：從任何地方觸發，在使用者所在之處與他碰面。
